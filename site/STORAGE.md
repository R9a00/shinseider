# ブラウザー保存の仕様

対象: GitHub Issues #1 / #2 / #3。申請文とフカボリは `static/project-store.js` を共用する。

- 既存の `shinseider_project` キー、version 1 の JSON、控えファイルの形式を維持する。
- 保存完了後にのみ「自動保存済み」と表示する。容量超過・アクセス拒否等は未保存と表示し、画面上の入力を維持する。処理中・未保存の離脱ではブラウザーの確認を要求する。
- 各タブで編集したフィールドのみ最新の保存データへ反映する。異なるフィールドは併存する。同じフィールドが読み込み時から変更されている場合は、同じ値の保存を除いて競合とし、保存全体を止める。
- 読み込み・比較・書き込みは Web Locks で直列化する。HTTPSまたはlocalhostで利用する。Web Locks非対応環境では安全のため自動保存せず、控え保存を案内する。
- 他タブの変更で編集中の入力を自動的に差し替えない。再読込で最新の内容を見る。競合時は先に控えを保存してから再読込し、内容を比較する。
- 控えには他タブの保存済み項目と、このタブの未保存の変更を含める。競合した項目は、このタブで作った文章を控えに残す。控え読込も形式検査と同じ競合検査を通す。
- 保存データが壊れている場合は無断で初期化・上書きしない。
- 診断の `shinseider_check` は最後に明示的に判定した回答を保存する。保存に失敗しても判定自体は表示し、結果が未保存であることを伝える。

公開切替時に既に開いていた旧版タブの保存処理はこの仕組みに参加しない。更新後は旧版タブの入力を控えに残して閉じ、新しいページを読み込むこと。Web Locksは旧コードによる書き込みを防ぐものではない。

カレンダー（Issue #4）は静的ICSのまま、ビルド日時と「その時点で終了していない日程」を収録範囲として説明する。診断の任意質問はQ4（Issue #5）。

## 検証

`node --test site/tests/*.test.cjs` は失敗、再試行、同時保存、競合、控えの内容、破損データを検証する。`python -m unittest discover -s site/tests -p 'test_*.py'` はICSの日時境界を検証する。

`python site/test_site.py` は実際に生成した13ページをlocalhostで配信し、隔離したChromiumで必須質問、保存失敗、複数タブ、控えの往復、進捗を検証する。日時を固定し、外部AI・アクセス解析へのリクエストは遮断する。GitHub Actionsでも同じコマンドを実行する。

## 応募書類の文脈

`application` に `shinseider.application-context/1` を保存します。6項目の本文・根拠・宿題・図表候補、出典、フォーマット/完成稿の抽出本文とSHA-256、点検結果を保持します。元のファイルは永続保存せず、ZIP出力時は再選択を求めます。entry/fukaboriの旧控えもこの追加データを含めます。追加データがない旧控えでは現在のapplicationを消しません。不正な追加データは保存前に拒否します。

点検対象のbindingは、点検結果自体を除く文脈と、公式要項・支援指示・出典の正本から計算します。材料・ファイル・正本のいずれかが変わると過去の結果として表示します。bindingの一致は対象の一致であり、意味的な品質の証明ではありません。保存失敗や同一欄の競合は既存の共通保存処理で表示し、控えを残せるようにします。


## 2026-10-30追加点検

- 公式6項目は、固定のIDと順序を保ったまま各欄単位で変更を比較する。初回利用の複数タブでも別の欄は共存し、同じ欄の競合は止める。増減する出典リストはリスト単位の競合検査を行う。
- 文脈JSONの控えとAI指示・ZIPは、共通のsnapshotを使い、他タブの保存済み項目とこのタブの未保存入力を含める。URLの入力途中などで形式検査に通らない場合も控えには入力を残す。形式を直してから再読込みする。
- ファイル・JSON・指示文・ZIP・点検結果の非同期処理は、開始後に材料が変われば取り込み/出力を止める。指示文と点検対象のIDは同じ開始時点の内容から生成する。
- 他タブの保存で作成済みの指示文を無効にし、入力欄は勝手に差し替えない。最新の入力欄を表示するには再読込みする。
- 点検結果の保存失敗は成功表示にしない。画面の入力は保持し、控え保存を案内する。

保存処理には試行番号を持たせる。古い保存が成功しても、それより後の入力が検査エラーで未保存なら、未保存表示と離脱時の確認を解除しない。
