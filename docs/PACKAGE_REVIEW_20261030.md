# 参考パッケージの照合・追加修正（2026-10-30）

## 対象と根拠

利用者提供の「シンセイダー修正パッケージ」のREADME.txtとchanges.patchを確認した。パッケージの基準は557af9f、照合先は本番反映済みのmain c781ae9。EXP PSの選択対象attgから現在の公開正本である独立リポジトリshinseider-next/shinseider-pocを確認し、既存作業を保全した別worktreeで統合した。

公式の根拠は[第7回応募書類要項](https://atotsugi-koshien.go.jp/slp/wpist/wp-content/themes/atotsugi202507/assets/pdf/application_form_requirements.pdf)（2026年9月改定、2026-10-30照合）の4〜7頁。本文7ページと表紙1ページ、PDF提出、5評価、6記載項目と評価の対応、サンプルが任意であることを確認した。各ページへの具体的な割付は、登録後に届くサンプル・案内を確認する説明とした。

## 採用・調整

- 応募文ページに、独自5テーマから公式6記載項目へ材料を再構成する案内、登録から書類提出までの手順、提出形式を追加。
- 予行審査を公式5評価に対応。字数・数字の個数・24ブロックのDoDは独自の整理基準であり、公式要件・審査通過とは別だと明示。
- 指示文生成をpreparation.pyで共通化。MCPのentry_interviewに残っていた未展開のtheme_elementsを解消。
- 関連照合で、MCPの章別深掘りには画面用保存データの項目IDが欠けていたことも確認。UIとMCPで同じ章指示文を生成し、無効な章番号を拒否する。
- 締切直前の案内を登録・書類提出に分け、両方の締切を提示。MCPの規模未確認時の資格説明も画面と整合させ、他条件の確認が不要に見える表現を修正。
- MCPの処理時間・正確性を保証する説明を見直し、ローカル記録とAIサービスでの処理、STDIOとWeb URLの違いを説明。

- OpenAIデスクトップとCodexの設定共有は前回公式資料で照合済みの説明を保持。パッケージ内の慎重な一般論を根拠として、対応機能を否定する変更はしていない。製品・版・Web版との区別は案内する。
