# 応募書類の文面をつくる指示文の通し試験（2026-11-12〜13）

申請書の準備ページの「締切が近いときは、応募書類の文面まで一気につくる」でAIに渡す指示文（`sprint_prompt_template`）を、最後まで会話させて確かめた記録です。

## 何を確かめたか

指示文を受け取ったAIが、次のとおりに動くかです。

- 一問ずつ聞き、話していない実績や数字を足さないか
- 何問かかるか
- 公式6項目のすべてに質問が入るか
- 経営の専門家なら聞くこと（新規事業に家業の何を使うか、誰がいくら払うか、最初の顧客と対価、体制・資金・リスク）を聞くか
- 最後に、表紙案・項目ごとの文面・宿題・公式5評価から見た弱い点・主催者のねらいの点検を出すか

## 方法

- 聞き手: 道具なしのチャットAI（Claude Sonnet をコマンドラインから呼び出し、システム指示は「一般のチャットアシスタント」だけ）に、サイトが渡す指示文をそのまま最初の発言として与えた。
- 答える側: 別のAIに、架空の後継予定者になってもらった。知っている事実の一覧だけを渡し、聞かれたことに短く答え、一覧に無いことは「わからない」と答えさせた。
- 会社は架空です。サイトの「書き方の見本」と同じ金属加工の会社を使っています。
- 会話の全文は `docs/document-prompt-dryrun-20261112/` にあります。試験に使った手順は同じ場所の `dryrun.py` です。

## この試験で言えないこと

- 答える側もAIによる模擬です。人が実際に答えたときの所要時間と負担は測っていません。「30〜60分」というサイトの表記は、確かめられていないため外しました。
- 試したAIは Claude Sonnet だけです。ChatGPT・Gemini・Grok での動作は未確認です。
- ボタンを押して、指示文が入った状態で各AIの画面が開くかは未確認です（検査ではリンクの長さの上限だけを確かめています）。
- 各版1回ずつの会話です。AIの応答は毎回変わるため、同じ結果が毎回出るとは限りません。
- 出てくるのは応募書類の素材です。8ページへの仕上げ、図や写真、事務局の様式への割付は、この指示文の範囲外です。
- 文面の良し悪しが書類審査の結果にどう効くかは、確かめていません。
