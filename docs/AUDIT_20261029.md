# シンセイダー全体点検（2026-10-29）

## 対象と判定

EXP PSで選択された登録済みattgから、README・既存動作確認記録・実装を辿った。現在公開される正本は独立リポジトリ `shinseider-next/shinseider-poc`、originは `https://github.com/R9a00/shinseider.git`。調査開始時の本番mainは557af9f。既存変更を保持し、別worktreeで検証・公開した。

現行サイトの公開12ページ、共有保存処理、ビルダー、11個のYAML、MCPの判定・計画・ファイル記録とセットアップ文書を対象とした。旧React/FastAPI版は現在の公開経路ではなく、前段の深掘り訂正以外の全機能再検証は対象外。構造・画面・掲載根拠・異常系を横断して調査したが、全記述の無誤謬や全環境の動作保証ではない。

EXP PSの個別Application登録、Work、Contract、Evidenceの完了承認は確認していない。この文書は検査記録であり、その代替ではない。QUALITY_GATE.mdは未追跡の草案で、機能の実装・承認を示すものとして扱わない。

## 修正

- 深掘り：月年換算漏れ、売上と費用の前提不一致、市場シェア、根拠のない健全性・統計・競合評価の断定。元データ・質問バンク・旧版を同期（先行PR #9）。
- 資格：家業があるだけの人を後継予定者と扱う選択肢、簡易質問だけでの完全適合の断定、承継時期だけで補助金の入口要件を満たすとする判定を訂正。MCP・進捗画面にも反映。
- 締切：前日・当日に過去の11/24や翌日の読み合わせを案内する不具合、締切後も受付中と表示する箇所を訂正。海外タイムゾーンでもJST基準で表示。
- 補助金：16次を「未発表」とする古い記載を受付期間10/2〜11/6 17:00へ更新。15次詳細は過去公募の参考情報と明示。
- 15次要領との照合：賃上げは従業員1人当たり、800万円超の補助部分は1/2以内である説明を追加。法人成りの例外、生産性向上の計画要件を補い、「全リスト」「間に合わない」の断定を撤回。
- 大会：地方出場者発表時期、準ファイナリストの扱い、SusHi Tech出展機会の対象条件を訂正。辞退自由・損失は時間だけという裏付けのない表現を見直し。
- 取り込み：null・配列・引用符入り未知キー・文字列中の波括弧で処理が止まる問題を修正。保存した本文にJSONコード例がある場合も末尾のセーブデータを復元。
- 表示・出力：コピー失敗を案内、ダウンロードURLを遅延解放、未知の項目を進捗の分子へ数えない。文字数と数字だけで内容を「OK」とする表現を訂正。
- 情報の扱い：外部AIでの処理・アクセス解析を説明し、運営者情報ページとの矛盾を解消。常時更新監視があるかのような説明と、未実装のconfidence強制機構をうたうコードコメントを訂正。
- リンク：北鋼シャーリングの404 URLを会社公式の現行URLへ訂正。任命名簿のプレスリリース掲載日を訂正。
- MCP：不正な保存mode・相対パス・シンボリックリンク経由の作業フォルダ外書込みを拒否。READMEの重複したmcpパスを修正。OpenAIの設定共有の説明は公式資料に一致し、その説明は保持。
- CI：ubuntu-latestが26.04に変わりPlaywright 1.55が起動できなかったため、対応OSの24.04に固定。回帰検査を省略せず追加。
