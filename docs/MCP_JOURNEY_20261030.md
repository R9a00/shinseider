# MCPを使った成果物作成・再開テスト（2026-10-30）

## 結論

MCPから取得した指示・質問・公式案内を使い、架空の事業者の骨子、レビュー、深掘りJSON、公式6項目への対応表を作成した。MCP経由の保存・再起動後の全文読戻しと、公開画面への取り込み・控えからの復元に合格した。成果物は材料の下書きとして検査済みであり、公式提出書類の完成・事業の成立を意味しない。

再開の試験で、既存MCPはファイル一覧しか返さず、本文読戻しのツールがないことを確認した。`workspace_read`を追加し、プロセス再起動後もMCPだけで本文を取り戻せるように修正した。

## 試験方法と範囲

- 対象はEXP PS選択のattg内にある公開正本shinseider-next/shinseider-poc、基準mainは24089c8。既存変更は保全し、別worktreeで実施。
- Python MCP SDK 2.3.0のClientSessionで、サーバーを別プロセスとしてSTDIO接続。資格、締切、逆算プラン、質問バンク、4種のうち今回使用したインタビュー・予行審査・DR・深掘り章指示を実際に取得した。
- 本セッションのAIが返却プロンプトを読み、固定の架空入力から問答・文章・レビューを作成した。MCPサーバー自体が文章を生成したわけではない。別AIアプリの自律実行や未知問題への検出率を測る試験ではない。
- 意図的に誤りを含めた初稿を負の対照とし、算術、実績と計画、未確認事項、公式要件と独自目安を点検した。初稿の誤りを知っている同じAIによる点検で、独立・盲検評価ではない。
- 保存先は隔離した試験フォルダ。実在利用者の入力・MCP設定・応募提出先は操作していない。

## 数値・内容の確認

ケースの仮定は月額5万円、月変動費3.5万円、継続3年、獲得費用12万円／社、月固定費20万円。

- 顧客当たり売上累計：5×12×3＝180万円。
- 変動費控除後の粗利相当累計：(5−3.5)×36＝54万円。獲得費用との比率4.5、回収8か月は固定費配賦前。
- 定常期20社：売上100万円−変動費70万円−固定費20万円＝10万円／月。初期投資・獲得費用・税等は別。
- 20社の獲得費用は240万円。年換算売上1,200万円を、初年度売上・達成実績として扱っていない。
- 初稿の承継時期、有償契約、競合不在、データ自由利用、回答時間保証の断定を除去。市場調査・支払意思・合意・稼働・継続率は未確認のまま保持。

`fukabori_coverage`には内容が誤った3行でもpassed_mechanical=trueを返すことを実測した。この値は文字形状のチェックで、算術・意味・事実の検証ではないという既存仕様に一致する。今回はレビューと検算を別に実施し、機械チェックだけを合格根拠にしていない。

## 不具合と修正

従来の`workspace_state`はファイル名・サイズのみを返し、「本文を読んで文脈を復元する」という案内に対してMCP内の読込み手段がなかった。CLI等の別のファイル読取り能力に依存する状態だった。変更前の`workspace_read`呼出しはUnknown tool、変更後は骨子・JSON・レビューの全文を取得でき、保存前と一致した。

`workspace_read(section, offset, max_chars)`を追加。長文を分割取得できる。書込みと共通のファイル名検査・作業フォルダ境界検査を使い、外部へのパストラバーサルやシンボリックリンクを拒否する。ファイル一覧と記録の存在だけで内容の完成を意味しないことも明記した。

## 実行結果と再検査

- Pythonテスト8件合格。10 tools／4 prompts／5 resourcesの実通信と再起動後の読戻し、長文分割、無効入力、作業フォルダ外参照拒否を含む。
- 公開画面：MCPの読戻し応答から5テーマ・2ブロック4項目を取り込み、保存・控え出力・別ブラウザー復元後まで全文一致。JS例外なし、外部AIへの通信は遮断。
- 生のMCP要求・応答は[mcp-calls.jsonl](mcp-journey-20261030/mcp-calls.jsonl)。修正前の失敗を含む。読戻し前後、生成物のハッシュと実行区分は[evidence.json](mcp-journey-20261030/evidence.json)、ブラウザー結果は[browser-check.json](mcp-journey-20261030/browser-check.json)。
- 回帰検査：`python -m unittest discover -s site/tests -p 'test_*.py'`。記録したMCP成果物の画面往復再検査：`python docs/mcp-journey-20261030/verify_browser.py`（公開URL、隔離ブラウザー。出力ファイルを更新する）。後者は記録済み出力の受渡し検査で、AIの文章再生成は行わない。

## 残件

この1ケースの検査で全業種・全入力の回答品質は保証できない。個別AIアプリへの登録、対話の実利用品質、未調査の市場・競合、公式サンプルのページ別割付、応募書類の実提出は未確認。既存のMCP利用者に新しい読込みツールを届けるには、ローカルのサーバーコードを更新し、クライアントを再接続する必要がある。
