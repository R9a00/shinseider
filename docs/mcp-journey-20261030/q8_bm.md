変動費=3.5万円×20社=70万円。固定費控除後=100−70−20=10万円／月（獲得費用・初期投資・税等の控除前）。
20社が通年契約した場合の年換算は1,200万円だが、初年度売上ではない。初年度は月別契約計画がなく未算定。
